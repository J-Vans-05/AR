# AR — Hummin / J.Van three-board version

`pcb-ar.html` uses the original `pcb-targets.mind` marker and provides previous/next controls for three PCB models:

- `board-1.glb`: Telesk iot
- `board-2-4dL293.glb`: TD4
- `board-3-L293D.glb`: TD2

The interface displays the Telesk and J.Van ownership marks and credits Hummin Robotic Co. and M.Javad Vahediyan. The exported PCB colours remain unchanged; only the unintended default metallic value was corrected.
